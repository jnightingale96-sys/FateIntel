# PEARL/SWASH visual alignment

The PEARL soil–groundwater view now uses the same flat technical-diagram language as
the TOXSWA/SWASH water–sediment view. The former landscape illustration, gradients
and glow treatment were removed in favour of outlined process compartments, muted
soil/water fills, thin labelled arrows and compact technical annotations.

The change is visual only. The following live PEARL elements remain connected to the
existing calculation output:

- scenario-specific soil horizons and model layers;
- target-depth/FOCUS PECgw assessment plane;
- percolation paths;
- dissolved and sorbed/total concentration particles;
- depth profile line;
- groundwater endpoint particles and context;
- simulation-time slider and animation.

The schematic continues to distinguish the native research screen from an official
FOCUS execution. No scientific equation, input mapping, output or regulatory claim
was changed by this visual alignment.
