# EnviroChem v2.11 interface review — 16 August 2026

The guided interface was reviewed against the product comments supplied on 16 August 2026 and rendered at a 1600 × 1000 desktop viewport before packaging.

## Design language

- Main cards and controls use crisp 1 px rules and nominal 2 px corners.
- Heavy drop shadows and pill-shaped containers are removed from the scientific workspace.
- Active selections use restrained edge markers rather than glow effects.
- Chart and flow connectors are reduced to thin strokes.
- Whitespace and typography carry hierarchy rather than decorative boxes.

## Scientific flow

The visible order is now:

`EU/US system → Tier 1–2 assessment → scenario-specific result → advanced regulatory refinement → molecular design`.

FOCUS PEARL and EnviroDesign are no longer placed before the exposure calculation.

## Release-path isolation

The guided engine executes three non-veterinary pathways in this build:

- Wastewater.
- Biosolids.
- Wastewater irrigation.

Direct surface water, direct soil and manufacturing catchment are shown as `Not wired`. A user click does not produce a placeholder concentration.

Wastewater does not display biosolids or irrigation soil PECs. Biosolids and wastewater irrigation have separate multi-year soil-series visualisations.

## Regulatory system switch

EU enables the current FOCUS PEARL refinement. US is deliberately shown as an implementation work package; PWC/PRZM/EXAMS outputs are not fabricated.

## EnviroDesign

The principal structure view uses the ordinary RDKit depiction. Human-readable structural regions are separated from exact fitted BIOWIN terms. The structure inventory now includes benzene-like aromatic rings and a set of transformation-sensitive functional motifs. Model intercept and molecular-weight terms remain inspectable but are demoted from the main R&D interpretation.

EnviroDesign no longer loads RDKit.js/WASM at application startup. The WebAssembly engine is requested only when the user opens the advanced structure analysis.
